# Scope boundaries

Required v1 is the requirements register, including a single-user macOS desktop experience on this MacBook, natural narration, listening, repeated imports, local embeddings and hybrid retrieval, OAuth-connected internet research with citations, offline prepared materials, backups, future courses and source-grounded ChatGPT tutoring. A missing course input or later provider audition does not delete a requirement.

Excluded: VR, AR, headsets, virtual campus, navigable world, ocean, decorative simulation, default path tracing or captured venues. Historical research suggestions for audience worlds or Babylon.js do not expand scope. Meaningful 2D interaction is primary; embedded subject-specific 3D requires an approved learning purpose. WebGPU is optional later enhancement with WebGL2 baseline.

No DRM removal, arbitrary imported/generated executable code, automatic account-memory/history synchronization, grading/clinical guarantees, fixed learner labels, or COMM 110 AI-generated outlines/citations. Internal source navigation for study is distinct from generating assignment citations.

Fresh local generative tutoring is deferred from required v1; local embeddings, local retrieval, cached and prepared learning are required. A local generative model still needs explicit budget/storage selection and real evaluation in Phase 13.1. Cross-platform synchronization, mobile/tablet access, hosted deployment and multi-user operation are excluded. A macOS desktop application/launcher is required; a local-browser app is the accepted interim development surface.

Phase 0 only produces administration and decisions. Phase 1 creates scaffold, Phase 2 design, Phase 3 dependencies. Phase boundaries and public/private data rules cannot be weakened to satisfy a check.
