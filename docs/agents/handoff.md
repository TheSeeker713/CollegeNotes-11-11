# Handoff

Record current phase/step/status, actual authorization reference and pass ID, changes, next permitted action, blockers, verified tree/commit, remote receipt and private evidence locations. Separate completed work from pending images, user decisions, application tests or account access. Summaries cannot manufacture approval.

At an ordinary phase boundary deliver a reviewable result, concise change/evidence summary and explicit stop. UI/UX review includes concrete tasks and the exact design/build revision. Record feedback, repair within that phase and retain both original and revised evidence.

A resume checklist: read AGENTS and current state; inspect relevant guides/manifests; verify actual user authorization, local changes and remote; locate real evidence; identify missing external artifact; act only within authorized scope. Do not publish private logs or course files in the handoff.
