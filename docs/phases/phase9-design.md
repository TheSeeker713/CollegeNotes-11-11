# Phase 9 interaction specification

AUTH-P9 implements the official activity and learning-history scope inside the existing Botanical/Brutalist glass shell. This document is a reviewable implementation specification, not owner visual acceptance.

Study offers a source-linked activity library and a collapsed authoring form. All six templates share title, question, approved source, prepared answer/rationale, rubric and graduated hints. User-authored content is local; model-authored content must retain provider/model attribution. No generation request is sent by this phase.

An attempt has independent durable response and teach-back text. Answers remain hidden until submission and explicit reveal. Hints advance one at a time. Retrying creates a new attempt without replacing history. Ordering uses ordinary labeled up/down buttons independent of card movement. Free text and ambiguous templates receive rubric-based review guidance, never a claimed grade.

Progress separates scored attempts, unassessed explanations and self-reported confidence; elapsed reading time is not evidence of mastery. The queue is bounded by an adjustable daily workload. Missed days preserve overdue items without punitive streaks. Schedule reset can be undone without removing attempts.

Short sessions present one item at a time, save unfinished text, hint and reveal state, and offer Continue, Pause and Resume. Prepared activities require the local service but no internet or AI connection. Source changes block stale work; source deletion removes dependent content.

All states use text labels and existing semantic glass controls across Botanical/Brutalist × Light/Dark. Appearance changes do not drive learning writes. Loading, unavailable module/source, save conflict/error, empty queue, paused and finished states have explicit messages. Owner manual review must cover keyboard operation, VoiceOver, 200% zoom, 1440×900 and 1024×700 windows, all four appearance variants and reduced motion/transparency. Agents do not run UI/UX tests.
