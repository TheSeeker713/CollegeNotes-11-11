## Return and selection rules

Round one selection approves a direction for further mockups only. Return all requested images and their actual dimensions before declaring the screen family ready. The owner must review flows, density, controls, errors/offline states and the optional aid. Any missing/illegible/mismatched screen stays incomplete and gets revised. Static images never demonstrate real keyboard, import, audio, account or saved-state functionality. Phase 2 cannot close, and Phase 3 cannot begin, merely because these prompts are written.
