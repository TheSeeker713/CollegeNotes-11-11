# Screen hierarchy and interaction routing

The screen map and flow JSON are the functional proposal for all visual directions. Final image selection may change composition but cannot delete required routes or recovery.

Desktop reference: 1440 × 900 CSS pixels. Keep the study source near the center, navigation on the left and optional notes/tutor context on the right. Header holds course/source location and material status. A bottom listening strip appears only when relevant; it cannot cover source text or focused controls. Home emphasizes the last task before secondary study suggestions.

Reader hierarchy: course > source title > section > passage > optional activity. Show source identity beside explanations. “View original” opens the matching page/region and returns to the same passage. Notes and tutor explanation are different tabs with explicit headings, not blended inline prose. A source drawer never requires navigating away to verify evidence.

Import hierarchy: choose input mode, assign course/source label, inspect each item's state, then open review or read. Supported inputs are screenshots, pasted text, notes, PDF, DOCX and DRM-free EPUB. Drop zones have a normal file-picker button and paste/note alternatives. Duplicate detection offers “Keep existing” and “Import as new version” when appropriate, not a destructive automatic replacement.

Study hierarchy: small objective, source context, question, learner attempt, then feedback. Answers are hidden before an attempt or explicit reveal. “Show a hint” is a secondary action. Progress shows attempted/review-needed evidence, not a grade. Spoken input is optional. Private user writing must survive route changes.

Practice hierarchy: task selection, own writing/recording, replay and observations. PQP labels remain Praise, Question, Polish. The question field encourages an actual question. The initial practice example is clearly synthetic; it is not a graded response. Rehearsal timing can be unconfigured until the user supplies course requirements.

Small windows: at 1024px hide the optional context drawer by default; at 768px collapse side navigation into an accessible menu; at 390px use one main column and separate Source / Notes / Tutor views. Keep course/source identity and Resume visible. Correction becomes Original / Extracted tabs that preserve scroll positions and edits. Reading order stays logical; no miniature desktop scaled down.

Draft course rules retain available source wording and uncertainty. The historical report can inform private context, but visual samples use invented text and “Not provided yet” for unknown official requirements. The ban on COMM 110 AI-generated outlines and sources/citations is present in the practice/tutor behavior, not just a footer disclaimer.

These are route/layout specifications. No clickable app, account connection, import or persistence behavior is implemented yet. Returned images must be paired with the interaction specifications and reviewed before Phase 2 can close.
