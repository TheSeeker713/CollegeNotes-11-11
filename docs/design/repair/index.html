DR-01 · First use

No courses yet

Create your first course

A name is required. No real course, assignment or provider is preloaded.

Recovery and confirmation behavior

Course creation failure preserves the typed name and offers Retry. Cancel returns to empty home.

DR-02 · Courses

Your courses

Synthetic course · demo only

Active / Archived / Trash filters. Create course; rename; edit description; choose reusable modules; export course.

Recovery and confirmation behavior

Archive removes a course from active navigation without deleting it. Restore returns it to Active. Export reports files, size, progress, failure and destination.

DR-03 · Course deletion

Review what will be removed

Delete Synthetic course?

Show material, notes, activities and index counts. Offer recoverable trash where practical or permanent deletion. Backups are separate copies and remain.

Recovery and confirmation behavior

Cancel is initially focused. Permanent deletion requires typed course name and explicit confirmation. Failed cleanup stays visible and retryable; do not claim success before completion.

DR-04 · Materials

Bring your own material

Import into Synthetic course

Files, images, PDF, DOCX, DRM-free EPUB, pasted text or new note. Batch list shows each item, original preserved, extraction state, duplicate handling and cancel.

Recovery and confirmation behavior

Invalid/corrupt/oversized item errors identify the item. Interrupted work offers safe retry. No silent overwrite of originals.

DR-05 · Correction

Original and extracted text

Sample passage · revision 2

Original opens on the left; editable extraction on the right. Source version, checksum and page/paragraph/region anchor remain visible. User-created notes have their own edit action.

Recovery and confirmation behavior

Save correction creates a revision and marks search, embeddings and activities stale. Save failure retains edits; leave-with-unsaved-changes offers Keep editing / Discard. Narrow desktop uses labeled Original / Text tabs.

DR-06 · Material export

Choose export scope

One item / Selection / Course / Portable backup

Choose original plus corrections and annotations. Show version, checksum manifest, size, destination and whether derived indexes are included. Credentials never included.

Recovery and confirmation behavior

Export runs locally with progress/cancel. Partial export is not labeled complete. Retry preserves source data; unsupported format is explained.

DR-07 · Material deletion

Review linked data

Move 2 selected items to trash?

Preview originals, extracted text, notes and derived study/index data. Show recoverable period if supported; permanent deletion is a separate choice. Backups remain independent.

Recovery and confirmation behavior

Deleted material immediately leaves retrieval/AI context. Cleanup interruption shows Pending cleanup. Restore rebuilds derivatives; permanent deletion cannot be undone.

DR-08 · Connections

Choose your AI services

No connected services

OpenAI / ChatGPT, xAI / Grok, Anthropic / Claude, Google / Gemini, and Add approved provider. Every card starts disconnected. OpenAI is optional and removable.

Recovery and confirmation behavior

Add asks for a label and supported authentication method. API credentials use protected local storage; OAuth opens provider sign-in only when an official integration route exists.

DR-09 · Authentication

Connect a service

API credential or supported account sign-in

OpenAI: API or documented app-server account route. Google: API or supported desktop OAuth. xAI and Anthropic: API; subscription OAuth unavailable until verified. No real credential field in this design gallery.

Recovery and confirmation behavior

Pending sign-in includes Cancel. Test connection reports success/error without exposing credentials. Expired/revoked access asks to reconnect; unsupported route explains why. Do not imply that subscription pays API bills.

DR-10 · Provider controls

Use services on your terms

Synthetic connection · not live

Provider enabled toggle; independent Tutor, Research, Narration, Transcription, Realtime voice capability toggles; capability model/default selector. Local embeddings remain local.

Recovery and confirmation behavior

Unsupported capabilities are labeled unavailable. Model, billing type, remaining allowance and optional hard usage ceiling shown before use. Unknown cost blocks paid use; no silent paid fallback.

DR-11 · Disconnect and remove

Keep local work

Remove Synthetic connection?

Disable stops requests. Disconnect clears local credentials. Remove also deletes service settings/default assignments. Course files, notes, study history and saved research remain.

Recovery and confirmation behavior

Warn that remote OAuth revocation may need network. Show local credential removal and remote revocation separately. Failure blocks use and offers Retry cleanup; never claim remote revocation offline.

DR-12 · Research

Find evidence deliberately

No research sessions yet

Select course, provider and query. Private excerpts are off by default; preview exact selected context and categories before Send. Billing and provider are visible.

Recovery and confirmation behavior

No provider/offline/limit/error state offers a remedy. Cancel preserves query and received evidence. No background research or automatic promotion into course requirements.

DR-13 · Research evidence

Inspect the claim

Synthetic claim · sample only

Claim links to source title, URL, publisher/author, retrieved date and exact excerpt. Uncertainty, conflicts and inaccessible sources appear alongside the claim.

Recovery and confirmation behavior

Save selected evidence into course, edit notes, export or delete session. Provider changes require a new explicit choice; existing evidence retains original provenance even after provider removal.

DR-14 · Offline and recovery

Your local work stays yours

Cloud service unavailable

Prepared reading, notes, search and saved audio remain local. New cloud responses need a connection. Sources/derivatives not prepared are honestly unavailable.

Recovery and confirmation behavior

Service outage preserves unsaved edits and offers retry; invalid saved route returns Home with notice. Course changes never display another course’s draft.

DR-15 · Reading and study

Source before explanation

No source selected

Source pane, user notes, study activity and optional audio have distinct headings. Resume last task with exact source/version/anchor. AI explanations remain labeled by provider.

Recovery and confirmation behavior

No study facts or assignment rules invented. Accessible 2D controls remain available without voice or 3D. Source correction marks dependent activities stale rather than presenting them as current.
